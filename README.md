# HSK 単語帳（HSK1〜5）

中国語検定 HSK の 1〜5 級の語彙を、間隔反復と小テストで覚えるための単語帳です。
ビルド不要の静的サイトなので、ファイルをそのまま置けば公開できます。

- 収録: **2498 語**（HSK 2.0 準拠 / HSK1 150 語・HSK2 149 語・HSK3 300 語・HSK4 599 語・HSK5 1300 語）
- 既定で出題されるのは HSK1・2（299語）。HSK3〜5 は設定でいつでも追加できます
- 各語に 簡体字・ピンイン・日本語訳・品詞・例文（中文/ピンイン/和訳）
- 記録はすべて利用者の端末内（localStorage）に保存。サーバーへは何も送りません

---

## 1. 手元で動かす

Python が入っていれば、それだけで確認できます。

```
cd hsk-vocab
python -m http.server 8765
```

ブラウザで <http://127.0.0.1:8765/> を開きます。

`index.html` をダブルクリックして `file://` で開いても動きます（データを `fetch` せず
`<script>` で読む構成にしてあるため）。ただしオフライン保存（Service Worker）だけは
`http://` または `https://` でないと有効になりません。

## 2. 広告（Google AdSense）を出す

広告枠は **学習の流れを止めない場所**にだけ置いてあります。
フラッシュカードと自己採点の画面には広告を入れていません。

| 枠名 | 出る場所 |
|------|----------|
| `home` | ホーム下部 |
| `list` | 単語一覧の末尾 |
| `result` | 小テストの結果画面 |

### 手順

1. AdSense にサイトを登録し、審査を通す
   （**審査時点では広告タグが無くても構いません**。先に 3. の公開を済ませてください）
2. 審査通過後、`index.html` の広告スクリプトのコメントを外し、`client` を自分の ID に変える

   ```html
   <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-あなたのID" crossorigin="anonymous"></script>
   ```

3. AdSense で「ディスプレイ広告」ユニットを 3 つ作り、`js/ads.js` を書き換える

   ```js
   var CONFIG = {
     enabled: true,                      // ← true にする
     client: "ca-pub-あなたのID",
     slots: {
       home:   "広告ユニットIDその1",
       list:   "広告ユニットIDその2",
       result: "広告ユニットIDその3"
     }
   };
   ```

4. `sw.js` の `var CACHE = "hsk-vocab-v7";` の数字を 1 つ上げて再公開する
   （上げないと、既に開いた人の端末で古いファイルが使われ続けます）

`enabled` が `false` の間は、枠の位置がわかるプレースホルダーが表示されます。

> **公開前に確認してください**: AdSense のポリシー上、プライバシーポリシーの掲示が必要です。
> このアプリは個人データを外部送信しませんが、AdSense は Cookie を使います。
> 「広告配信に Cookie を使う旨」と「無効化の方法」を書いたページを用意し、
> ホーム下部の文言からリンクするのが無難です。

## 3. 公開する

### GitHub Pages（無料・手軽）

```
cd hsk-vocab
git init
git add .
git commit -m "HSK 単語帳"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

GitHub のリポジトリ → **Settings → Pages** → Source を `main` / `/ (root)` にすると、
`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

### Netlify / Cloudflare Pages

フォルダごとドラッグ＆ドロップするだけで公開できます。ビルドコマンドは不要です。

### 公開後

スマホで開き、ブラウザのメニューから「ホーム画面に追加」するとアプリとして起動します
（`manifest.webmanifest` と `sw.js` により、オフラインでも開けます）。

## 4. 中身の直し方

### 単語を足す・直す

`data/hsk1.js` 〜 `data/hsk5.js` の 1 行が 1 語です。

```js
{w:"爱", p:"ài", j:"愛する、好む", pos:"動",
 ez:"我爱我的家人。", ep:"Wǒ ài wǒ de jiārén.", ej:"私は家族を愛している。"},
```

| キー | 意味 |
|------|------|
| `w` | 簡体字 |
| `p` | ピンイン |
| `j` | 日本語訳 |
| `pos` | 品詞（名・動・形・副・量・代・助・介・連・嘆・数・固・句） |
| `ez` / `ep` / `ej` | 例文の 中文 / ピンイン / 和訳 |

学習記録は `級:簡体字`（例 `1:爱`）で紐づけています。**既存の語の `w` を変えると
その語の記録が切れます**。訳や例文の修正は記録に影響しません。

### 復習の間隔を変える

`js/srs.js` の先頭にあります。

```js
var INTERVALS = [1, 2, 4, 8, 16, 32, 60];   // 箱ごとの「次に出るまでの日数」
```

箱 3 以上を「習得」として扱っています。

### アイコンを作り直す

```
python icons/make_icons.py
```

`icons/make_icons.py` の `GLYPH` と `JADE` を変えると字と色が変わります。

### 配色を変える

`css/app.css` の冒頭にある `:root` のトークンだけを書き換えてください。
明るいテーマ・暗いテーマの 3 か所（`:root` / `prefers-color-scheme: dark` /
`[data-theme="dark"]`）に同じ変数が並んでいます。

`dev/selftest.html` をサーバー経由で開くと、77 項目の自己診断が走り、
画面上に `RESULT 77/77 passed` と結果一覧が出ます。

データ件数、復習間隔の計算、日付またぎ、学習の一巡、小テスト 10 問、一覧の検索と絞り込み、

設定の保存までを実際に画面を操作して確かめます。単語を足したあとや、

`dev/` はアプリ本体からは参照されません。公開時に消しても動作に影響しません。

## 6. 学習の仕組み

- **出題順** — 復習期限が来た語を先に、残りを未学習の語で埋めます（1 回 = 目標語数）
- **自己採点** — 「わからない」はその回の最後にもう一度出し、箱を 0 に戻します。
  「あいまい」は箱を 1 つ下げて翌日に、「わかる」は箱を 1 つ上げて間隔を伸ばします
- **小テスト** — 間違えた語は箱 0（要復習）に引き戻します。
  正解しても箱は進めません（自己採点と二重に効かないようにするため）
- **連続日数** — 学習か小テストをその日に 1 回でも行うと加算。
  途切れると表示は 0 に戻りますが、最長記録は残ります

## 7. 既知の制約

- 記録はブラウザごと・端末ごとです。端末間の同期や、履歴の消去からの復元はできません
- プライベートブラウズなどで `localStorage` が使えない場合、学習は続けられますが記録は残りません
  （ホーム下部にその旨を表示します）
- 発音の読み上げは端末標準の音声合成（Web Speech API）を使います。録音ファイルは
  一切持たないため、中国語音声が入っていない環境（主に Windows）ではボタン自体が
  出ないか、発音が不自然になることがあります
- HSK 2.0 の公式語彙表は公開版によって数え方に差があります（「虽然…但是…」を 1 語とするか
  2 語とするかなど）。本アプリは HSK1 を 150 語、HSK2 を 149 語、HSK3 を 300 語、
  HSK4 を 599 語、HSK5 を 1300 語として収録しています。HSK4 は出典PDF自体に欠番
  （676→678）があり、600語のうち599語分しか収録できていません。公開前に内容をご自身で
  確認してください
- HSK3 には「花」(使う/花)・「只」(zhī/zhǐ) のように、同じ漢字で読みや意味が違う語
  （多音字）が含まれます。アプリ内部では自動でピンインや連番を足して区別しています
- **HSK5 のデータ来歴について**: HSK1〜4 は、ピンインや日本語訳・例文に公式または
  準公式の出典（見出し語に紐づく例文つきの語彙リスト）がありました。HSK5 については
  見出し語の並び（1300語・旧HSK 2.0 準拠）はManchester大学Confucius Instituteが配布する
  公式語彙表（漢字のみ）を採用していますが、**ピンイン・日本語訳・例文はすべて本アプリの
  ために新たに作成したもの**で、公式の例文を基にしたものではありません。誤訳や不自然な
  例文が残っている可能性があるため、特に試験対策に使う場合は内容をご自身でも確認して
  ください

```

js/store.js                学習記録の保存と読み出し

js/tts.js                  発音読み上げ（Web Speech API のラッパー）
js/app.js                  画面の組み立てと操作
data/hsk1.js               HSK1 の 150 語
data/hsk2.js               HSK2 の 149 語
data/hsk3.js               HSK3 の 300 語
data/hsk4.js               HSK4 の 599 語
data/hsk5.js               HSK5 の 1300 語
icons/                     アイコンと、その生成スクリプト
dev/selftest.html          自己診断（公開不要）
```
